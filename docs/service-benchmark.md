# Market Research Agent — 유사 서비스 비교

확인일: 2026-10-15 · 공식 제품 페이지·문서·개발자 앱 소개 기준

**먼저 볼 서비스는 Messari Copilot, DefiLlama LlamaAI, Perplexity Deep Research다.** 각각 암호자산 조사 보고서, 시장 데이터 분석, 출처를 따라가는 조사 흐름을 벤치마킹하기 좋다. 이는 현재 프로젝트와의 적합성에 대한 판단이며, 서비스의 정확도 순위가 아니다.

비교 범위는 [현재 README](../README.md)의 **BTCUSDT·ETHUSDT·BNBUSDT 시장 데이터와 공식 문서를 활용하는 리서치 에이전트**다. 사업 타당성·소비자 설문·마케팅 시장조사 서비스는 범위에 넣지 않았다.

목적과 기능은 링크한 공식 자료를 기준으로 작성했다. 장점은 해당 기능이 사용자에게 주는 이점에 대한 분석이고, 한계는 공개된 제약과 데이터 해석상 주의점을 구분해 적었다. User Flow는 공식 설명을 바탕으로 재구성한 대표 흐름이며, 모든 화면을 직접 실행해 확인한 결과는 아니다.

**현재 프로젝트에서 우선 벤치마킹할 부분**

1. **Messari Copilot — 조사 과제와 결과 형식.** 어떤 질문을 유도하고, 짧은 답변과 심층 보고서를 어떻게 구분하는지 본다. 추천 질문과 템플릿의 역할부터 살펴보면 된다.
2. **LlamaAI — 질문을 수치와 시각 자료로 확인하는 과정.** 서술만 읽는 대신 표·차트와 함께 확인하게 하는 방식을 본다. 공식 소개는 [출처가 포함된 심층 보고서와 추천 질문](https://defillama.com/research/spotlight/llamaai-llm-for-crypto-and-tradfi)도 설명한다.
3. **Perplexity — 답변에서 근거로 이동하는 과정.** 인용을 열어 확인하고 질문을 좁혀가는 흐름을 본다. [공식 소개](https://www.perplexity.ai/en-GB/hub/blog/introducing-perplexity-deep-research)는 반복 검색·자료 검토·보고서 작성 과정을 설명한다.

**우리 서비스의 초기 User Flow 후보 — 아직 확정 설계가 아님**

종목·기간 입력 → 누락된 조건 확인 → 시장 수치와 공식 문서 수집 → 변화 비교와 관련 공식 정보 요약 → 출처·수집 시각·확인하지 못한 내용 확인 → 추가 질문.

예시 과제는 “지난 7일 BTC·ETH·BNB의 가격 변화를 비교하고, 관련 공식 문서에서 확인되는 내용을 함께 정리해줘”다. 기간이 있는 질문이라면 문서가 그 기간에 발행·갱신된 자료인지도 표시해야 한다. 기존 기술 문서를 최근 뉴스처럼 제시해서는 안 된다.

**제품 방향에 대한 판단:** ‘코인 질문에 AI가 답한다’는 기능만으로는 위 서비스와 차별화하기 어렵다. 특정 사용자가 반복해서 하는 조사 한 가지를 고르고, 어떤 원문과 수치를 어떤 순서로 확인하게 할지 정하는 것이 다음 단계다. 가격 변화와 같은 시기에 발표가 있었다는 사실만으로 가격 변화의 원인이라고 단정하지 않는 것도 필요하다. 이 문서는 시장 수요나 차별성이 검증되었다는 뜻은 아니다.

**확인 범위와 남은 검증**

- 유료 계정으로 동일 질문을 실행한 비교, 답변 정확도·인용 적합성·응답 시간·한국어 품질 측정은 하지 않았다. 정확한 요금도 비교하지 않았다.
- SoSoValue 공식 웹사이트는 조회 시 403 응답으로 본문을 읽지 못해, 개발자가 게시한 Google Play 소개를 기능 근거로 사용했다.
- Token Metrics는 과거 AI 등급·챗봇 소개와 현재 홈페이지의 강조점이 달라, 현재 공개 홈페이지의 시그널·전략 선별을 기준으로 정리했다. 과거 기능의 종료 여부는 확인하지 않았다.
- Messari의 기존 API 문서는 현재 Legacy로 표시되며 [새 문서](https://docs.blockworks.com/introduction)로 안내한다. 이번에는 제품의 사용자 흐름을 비교했으며 API 도입이나 구현 구조를 결정하지 않았다.
- 현재 구현 코드와 README의 설계·운영 규칙은 변경하지 않았다. 기능과 접근 조건은 이후 바뀔 수 있다.
