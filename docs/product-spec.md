# 현재 제품 범위

**실제 금융 뉴스·공식 거시 자료를 검색하고 인용 보고서와 실행 근거를 남기는 로컬 연구 도구다.** 일반 실행은 live + OpenAI + web이다. 합성 자료는 회귀 검사에만 남겼다. 실제 Astra 평가 점수·공개 서비스 수요는 아직 검증하지 않았다.

## 조사와 자료

뉴스·거시 질문에는 가격 종목·기간을 요구하지 않는다. OpenAI hosted search/read가 자료를 찾고, 앱은 제공자 URL 인용의 구조를 검사한다. 질문 언어 또는 명시한 출력 언어로 답하도록 지시한다. 앱이 기사 전문을 직접 수집하거나 문장별 진위를 검증하는 것은 아니다.

가격 조건을 인식하면 BTCUSDT·ETHUSDT·BNBUSDT의 완료된 UTC 일봉 1개 또는 7개를 조회할 수 있다. 전 종목에 같은 `[start, end)`를 적용한다. 원 일봉 문자열로 40자리 Decimal 변화율을 계산하며 표시 반올림을 분리한다. 누락·순서·중복·미완료·가격 범위 오류는 거부한다. 모델이 가격을 만들어내지 않게 한다.

## 결과의 의미

- `completed`: 수치 또는 웹 실행·인용 형식 계약을 충족했다. 전체 답변의 진위와 의미적 지지를 입증한 점수는 아니다.
- `partial`: 일부 수집만 성공했다. 웹 조사 실패 시 성공한 가격 근거도 보존한다.
- `insufficient_evidence`: 원인 등 핵심 주장에 대한 한계를 표시한다. 기사가 인용돼도 인과관계가 입증되지는 않는다.
- `needs_clarification`·`unsupported`: 제한된 가격 경로의 지원 계약 밖이다.
- `error`: 키 부재·모델/자료 오류·미완료·인용 누락 등으로 실행을 완료하지 못했다.

## 실제 평가

[evaluate](live-research-evaluation.md)는 원문에 근거한 12개 질문·6개 사건의 파일럿을 실제 모델에 실행한다. 실행 성공·기준 URL 확보와 정답·인용 지지·시점·언어 점수를 나눈다. 의미 점수는 원문 대조 검토 전까지 null이다. 자동 자기 채점이나 정규식 숫자 일치를 정답으로 쓰지 않는다. 기존 20개 합성 사례는 regression 명령으로 보존한다.

## 경계와 미구현

서버는 127.0.0.1로만 바인드한다. 키는 서버 환경변수에서 읽고 저장하지 않는다. 과거 기록은 유지하며 재현은 기록된 HTTP만 소비한다. [서버 계약 확인](integration-status.md)으로 오래된 프런트/백엔드 조합을 안내한다.

범용 자율 행동 루프·Qwen과 공유하는 외부 검색·기사 전문 크롤러·독립 사실 검증·FRED 등 거시 시계열 전용 API·앱 자체 MCP 서버는 아직 없다. GitHub와 이 대화의 GitHub 커넥터는 이미 연결돼 있다.
